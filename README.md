## Objetivo da atividade
Esta atividade teve como objetivo analisar uma página web com problemas estruturais e aplicar correções utilizando HTML5 semântico, visando melhorar a acessibilidade, organização e legibilidade do código.

---

## Página analisada
O código analisado apresentava uma estrutura baseada em HTML 4.01 Transitional, contendo elementos automáticos gerados por rastreamento e extensões do navegador.

---

## Problemas encontrados

### 1. Uso de HTML obsoleto

O código não utilizava elementos estruturais como:

<header>
<main>
<section>
<article>
<footer>

Impacto:

Dificulta interpretação por leitores de tela
Reduz acessibilidade
Prejudica SEO

<!DOCTYPE html PUBLIC "-//W3C//DTD HTML 4.01 Transitional//EN">
